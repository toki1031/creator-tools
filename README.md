# Creator OS Sprint 3.9.2 — 字幕プレビュー同期・素材保持・Undo版

## 1. 手動字幕改行をプレビューへ即時反映
Sprint 3.9.1で動画出力側に対応した手動改行を「3. 字幕・BGM」の字幕プレビューにも反映。
- 1回改行：同一字幕内の強制改行
- 編集中の改行をプレビューへ即時反映
- 字幕サイズ等の既存設定は維持

## 2. 台本再分割時に既存素材を保持
「2. シーン・ナレーション」→「台本から自動分割」で、既存シーンがある場合は確認を表示。
続行すると同じ順番のシーンへ以下を可能な限り引き継ぐ。
- 画像
- 動画
- モーション
- トランジション

文章が変わったシーンのナレーションは、古い音声と新しい台本の不一致を防ぐため再生成対象。
文章が同一なら既存ナレーションと尺を保持。

## 3. 1つ前に戻す
シーン編集に「↶ 1つ前に戻す」を追加。
- 台本から再分割
- シーン削除
- 空シーン追加
の直前状態へ復元可能。
もう一度押すと復元前状態との行き来も可能。

## 方針
制作途中の軽微な台本修正で、画像を毎回アップロードし直す手戻りを減らす。
