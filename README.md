# Creator OS Sprint 3.0 — ブラウザ動画生成エンジン初版

## 実装内容

- シーン画像を指定秒数で連結
- ズームイン／ズームアウト／左右パン
- シーン間フェード
- 編集済み字幕の映像合成
- 登録BGMのループ、音量、フェードイン・アウト
- 9:16のCanvasプレビュー
- 先頭10秒の動作テスト生成
- 3分以内の全編生成
- 生成進捗、中止、動画プレビュー、保存、共有
- Safari等がMP4録画に対応する場合はMP4
- MP4非対応環境ではWebMへ自動フォールバック

## 初版の制限

- ブラウザ読み上げ（SpeechSynthesis）のナレーションは、まだ動画へ録音しません。
- 全編生成は3分以内です。長時間BGM動画は、今後の高速／サーバー生成エンジンで対応します。
- 動画生成は実時間と同程度かかります。
- 生成中はSafariを前面表示し、画面をロックしないでください。
- 1080×1920・60fpsは端末負荷が高いため、最初は720×1280・30fpsを推奨します。

## 検証

- 全JavaScriptファイルの構文チェック
- モジュール参照ファイルの存在確認
- 動画プロジェクト検証ロジックの単体確認

実際のMP4生成可否と安定性は端末・Safariの対応状況に依存するため、iPhone実機で先頭10秒テストを最初に行ってください。
