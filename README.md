# Creator OS Sprint 3.9.1 — 手動字幕改行対応版

## 字幕の手動指定
字幕欄でユーザーが入力した改行を自動分割より優先します。

### 1回改行
同じ字幕カード内で強制改行。

例:
本田宗一郎は失敗を恐れず、
何度も挑戦を続けました。

→ 動画でもこの2行を同時表示。

### 空行
字幕カードの強制切り替え。

例:
本田宗一郎は失敗を恐れず、

何度も挑戦を続けました。

→ 前半字幕 → 後半字幕 の順に表示。

## 自動処理との関係
手動指定 > 文末 > 読点 > 意味のまとまり > 助詞・接続語 > 文字数

手動指定がない文章ではSprint 3.9.0の日本語自然字幕分割をそのまま使用。
