# Creator OS Sprint 3.9.0 — 日本語自然字幕分割版

## 改善点
長い字幕を単純な文字数位置で切る方式から、日本語の意味の区切りを優先する方式へ変更。

優先順位:
1. 文末（。！？）
2. 読点（、）
3. 意味のまとまり
4. 助詞・接続表現の境界
5. 最後の手段として文字数

## 方針
- maxCharsを少し超えても、自然な読点位置を優先
- 「は・が・を・に・で・と・の」等が次字幕の先頭に孤立しにくい
- 3文字以下の短すぎる断片は前後へ結合
- 長すぎる節だけを追加分割
- ナレーション尺に対する字幕タイミング配分は従来どおり、文字量＋句読点の間を考慮

例:
本田宗一郎は失敗を恐れず、何度も挑戦を続けました。
→ 本田宗一郎は失敗を恐れず、
→ 何度も挑戦を続けました。

Kokoro、シーン別ナレーション、WAV実尺同期、BGMダッキング、最終素材確認は維持。
