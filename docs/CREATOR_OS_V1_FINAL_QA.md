# Creator OS v1.0｜最終QAチェックリスト

基準日: 2026-09-07
対象: v1.0完成候補

## 目的

Creator OSの主要制作経路を、細かな機能単位ではなく1本の実運用フローとして確認する。新機能探索ではなく、v1.0完成判定のための回帰確認を行う。

## 安全ルール

- 既存ユーザーのプロジェクトを削除しない
- SafariのWebサイトデータを削除しない
- IndexedDB / localStorageを削除・初期化しない
- 既存本番プロジェクトを破壊しない
- 必要な確認は新規QA用プロジェクトで行う
- AI提案は自動適用されないことを確認する

## A. 起動・保存

- [ ] iPhone SafariでCreator OSが正常起動する
- [ ] 起動中のまま無限停止しない
- [ ] 新規QA用プロジェクトを作成できる
- [ ] 保存状態が「保存済み」まで進む
- [ ] 再読込後もプロジェクトが開ける

## B. 台本・シーン

- [ ] 表示用台本 / 音声用台本を編集できる
- [ ] 台本からシーン分割できる
- [ ] シーン本文を編集できる
- [ ] シーン順序・秒数・動き・切り替えを変更できる
- [ ] Undo / Redo対象の文字編集が正常

## C. 画像素材・AI提案

- [ ] 画像をアップロードできる
- [ ] 素材ライブラリから画像を選択できる
- [ ] 複数シーンで素材を再利用できる
- [ ] AI画像提案または「学習中」が表示されても操作を妨げない
- [ ] motion / transition AI提案または「学習中」が表示されても操作を妨げない
- [ ] AI提案だけで画像・motion・transitionが勝手に変わらない
- [ ] 再読込後も選択画像が保持される

## D. ナレーション・字幕・BGM

- [ ] ナレーション設定を開ける
- [ ] 既存の音声生成 / 音声参照経路が操作可能
- [ ] 字幕本文・改行・位置・プリセット等を編集できる
- [ ] 字幕プレビューが表示される
- [ ] BGM音源を設定できる
- [ ] volume / ducking / loop / fade設定が保存される

## E. 出力

- [ ] Output画面を開ける
- [ ] 最終素材チェックが成立する
- [ ] MP4生成の開始確認ダイアログが表示される
- [ ] 対応環境でMP4生成が完了する
- [ ] 生成結果が想定解像度・fps・尺のMVP条件を満たす
- [ ] ナレーション / BGM / 字幕 /画像の同期に重大な崩れがない

## F. 公開情報

- [ ] タイトル等の公開情報を編集できる
- [ ] 公開情報承認が現在状態と一致して記録される
- [ ] 保存・再読込後も保持される

## PASS基準

以下をすべて満たした時点でv1.0完成候補をPASSとする。

1. 自動regression tests PASS
2. Production build PASS
3. Cloudflare deployment PASS
4. iPhone SafariのA〜F主要経路で重大不具合なし
5. データ消失・保存破損・起動不能・MP4不能のP0 blockerなし
6. AIがadvisory-onlyで、既存設定を自動変更しない

## v1.1以降へ送るもの

- 画像AIの意味理解・embedding
- 高度な画像生成 / 動画生成モデル
- 大規模ストレージmigration
- UI全面改修
- 新しいAI提案種別
- v1.0完成に必須でない性能改善
