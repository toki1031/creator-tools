# Creator OS MVP 動画書き出し QA

対象: Issue #7「MP4書き出しをMVP出力仕様で検証する」

## MVP基準
- YouTube Shorts / 60秒以内
- 9:16 / 1080×1920 / 30fps
- MP4。MediaRecorderで明示指定できる場合はH.264(avc1)+AAC(mp4a)をgeneric MP4より優先
- 画像・字幕・ナレーション・BGMが意図したタイミングで同期

## 画像素材ライブラリ回帰確認
1. シーン画像は `scene.imageData` ではなく画像素材ライブラリから割り当てる。
2. 出力画面で「画像 2/2」と最終確認サムネイル2件が同じ画像を表示することを確認する。
3. 「この内容で動画生成を許可」が誤って「映像素材なし」で拒否されないことを確認する。
4. シーン別ナレーション2/2の場合、素材診断も「シーン別ナレーション 2/2」と表示する。

## 短尺確認
1. 画像・字幕・シーン別ナレーション・BGM入り10〜20秒projectを用意。
2. 1080×1920 / 30fps / 標準品質で全編生成。
3. 結果欄でMP4、生成Blob 1080×1920、取得できる場合captureStream約30fpsを確認。
4. 再生して画像切替・字幕・ナレーション・BGM・duckingを確認。

## 55〜60秒確認
1. 合計尺55〜60秒のprojectを作る。
2. 1080×1920 / 30fpsで全編生成。
3. 画面を閉じず完了すること、再生時間、同期を確認。
4. 「保存後ファイルを検証」で保存経路による解像度変化がないことを確認。

## 失敗時
表示された「原因・詳細・次の操作」に従う。メモリ系は他タブや重いアプリを閉じて先頭10秒から再試行。720×1280は原因切り分け用で、MVP完成判定は1080×1920。codec系はSafari更新・通常再読込・対応端末を試す。音声decode系はMP3/M4A/AAC/WAVを再登録する。

## PASS条件
短尺と55〜60秒の双方で1080×1920 / MP4 / capture約30fpsを確認し、目視・聴取で画像・字幕・ナレーション・BGM同期が問題なく、失敗時に原因と次操作が表示されればIssue #7完了。


## 動画生成開始ダイアログ回帰確認
- 動画生成開始前は `window.confirm` ではなくCreator OS画面内のdialogを表示する。
- 「キャンセル」ではレンダーを開始せず、AudioContextも新規作成しない。
- 音声を使う場合、「生成を開始」ボタンのユーザー操作内でAudioContext生成と `resume()` を呼び、その後に素材読み込み・動画生成へ進む。
- Cloud Browser/E2Eではネイティブconfirmで操作セッションを遮断しないことを確認する。
- iPhone Safariではシーン別ナレーションのみ／BGM併用の双方で音声が入ることを実機確認する。
